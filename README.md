# Sales Data Analysis Using Python

## Project Overview
This project analyzes sales data to understand product performance, total revenue, and quantity sold using Python.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- VS Code

## Dataset
The dataset contains product names, quantities sold, and product prices.

## Analysis Performed
- Calculated revenue for each sales record.
- Analyzed total quantity sold by product.
- Compared revenue generated by each product.
- Created bar charts and a pie chart for visualization.
- Generated business insights from the sales data.

## Key Findings
- **Total Revenue:** ₹2,54,500
- **Best-Selling Product:** Mouse — 11 units sold
- **Highest Revenue Product:** Laptop — ₹1,35,000
- **Lowest Revenue Product:** Mouse — ₹5,500

## Conclusion
The analysis shows that laptops generated the highest revenue, while mice had the highest sales quantity. These insights can help businesses understand product performance and make better decisions.
